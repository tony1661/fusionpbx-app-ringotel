# Changelog

## 1.1.0

- Sync Now pushes every extension to Ringotel, so it also corrects changes made in the Ringotel portal. The separate Full Sync button was removed.
- New "In Ringotel only" filter on the Activations page lists Ringotel users that aren't linked to an extension. They can be deactivated or deleted from there.
- The Activations and Domains pages show how many unlinked Ringotel users each domain has.
- Dry run now also applies to the Activate and Deactivate buttons.
- Requires running the upgrade with Schema ticked to add the unlinked_count column.
